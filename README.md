# 🎬 Movie Theater Booking System

An interactive and user-friendly web-based **Movie Theater Booking System** designed to provide a seamless cinema ticket reservation experience. Users can browse currently showing movies, explore theater facilities and food menus, access a user dashboard, and book tickets online.

---

## ✨ Features

- **🏠 Home & Movie Showcase:** Browse featured and currently showing movies (e.g., *Jurassic World Rebirth*, *Thunderbolts*) with attractive visuals.
- **🔐 User Authentication:** Dedicated Login interface directing users to a personalized post-login home experience.
- **📊 User Dashboard:** Interactive dashboard to view movie details, showtimes, and manage bookings.
- **🎟️ Ticket Booking (`booknow.html`):** Easy-to-use booking interface for selecting movies and reserving seats.
- **🍿 Theater Facilities & Food (`Food.html`):** Explore available cinema amenities, snacks, and beverages before watching a movie.
- **📞 Contact & Support:** Dedicated contact page for user inquiries, feedback, and customer support.

---

## 🛠️ Technologies Used

- **HTML5** – Structuring the web pages and content.
- **CSS3** – Custom styling, layouts, and responsive design.
- **JavaScript** *(if applicable)* – Interactive UI elements.
